Ты помогаешь мне развивать сайт **HMSTR.FM**. Отвечай по-русски, коротко и по делу.

## Контекст
Моя подруга проводит радио-стримы на **Twitch**: зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, она слушает, ставит оценку и иногда добавляет трек в плейлист. Сайт нужен, чтобы ей было удобно это делать.

## Файлы и хостинг
- Сайт: https://hmstrfm.vercel.app/ (GitHub → Vercel). Чистый HTML/CSS/JS, без сборки, без сервера.
- `index.html` — панель ведущей. `overlay.html` — оверлей для OBS. `sfx.js` — синтез звуков (общий). `og.png` — баннер превью ссылки 1200×630.
- Есть вторая, отдельная версия для другого канала — **M1Z.FM** (свой репозиторий, свои `index.html` + `overlay.html`). Этот промт только про HMSTR.FM.

## Что умеет панель (сверено с кодом)
- **Очередь:** заявка вручную или из чата Twitch → очередь (▶ играть сейчас, ✕), нумерация, VIP, перетаскивание, дедупликация по нормализованной ссылке, лимит длины трека (`cfg.maxmin`, проверка для YouTube).
- **Плеер:** YouTube IFrame API (название/автор через `getVideoData`, прогресс-бар с перемоткой), Spotify и SoundCloud через iframe, остальное — винил и «↗ Открыть». Громкость 50% по умолчанию (`hmstr_vol`), только для YouTube. Для видео без встраивания: «↻ Обновить плеер», «↗ Открыть в новой вкладке», обложка по названию через iTunes Search (`c.cover`, флаг `c.noemb`).
- **Оценка:** 1–10 с подписью, эффекты на 9–10, 💀 и звук `SFX.fail` на 1, заметка, теги (Качает, Скучный, Весёлый, Не очень, 50/50), быстрые комментарии (Добавлен в плейлист, Прикольный, Мимо), «В плейлист» / «Пропустить» / «Следующий».
- **Чат Twitch (бот):** анонимный `wss://irc-ws.chat.twitch.tv` (`justinfan…`, только чтение). Команды по умолчанию `!заказ, !sr, !order`; лимит заявок на зрителя, пауза между заявками, чёрный список ников и слов, очередь «На проверке» (`S.pending`). Голосование чата `!1…!10` (`votes`, `vn`, `vavg`). Принимает ссылку вместо ника канала (`chanName`). Работает, пока панель открыта.
- **Эфир:** ON AIR, слепое прослушивание (B), таймер трека, ☕ «Перерыв» (K) и ⏳ «Скоро начнём» (L): `brk={on,until,kind}`, дублируется в `hmstr_brk`. Компактный режим, статистика эфира (средняя, график, гистограмма).
- **Итоги:** хит-парад вечера с фильтром по тегам, «кураторы вечера» (8+), «Лучшее за 30 дней / за всё время» из архива `hmstr_arch`, PNG для сторис 1080×1920 (стили по темам, фото ведущей в `hmstr_photo`), экспорт плейлиста (список, CSV, ссылки, поиск в Яндекс Музыке/Spotify, «▶ Плейлист на YouTube» через `watch_videos?video_ids=`, до 50).
- **Лёгкий режим** (Настройки, `cfg.lite`, `data-lite=on`): выключает анимации фона, размытия `backdrop-filter` и свечение `.ambient` — на случай лагов (особенно на Mac).
- **Темы:** 10 тем с анимированными фонами (hamster, neon, space, lagoon, sakura, matrix, retro, volcano, platinum, stage), светлая/тёмная/авто (`cfg.mode`, клавиша D), переключатели анимаций.
- **Плейлист:** копирование «Исполнитель – Название» с очисткой «Official Video / Lyrics / HD…» (`cleanTitle`, `plName`), опция «ссылки».
- **Звуки** (`sfx.js`): джингл, аплодисменты на 9, эйрхорн на 10, фейл на 1. Играют в панели или в оверлее (`cfg.snd`), громкость `cfg.sndVol`.
- **Данные:** `localStorage`-ключи: `hmstr_fm_v1` (состояние `S`), `hmstr_cfg`, `hmstr_theme`, `hmstr_vol`, `hmstr_arch`, `hmstr_brk`, `hmstr_photo`. Экспорт/импорт JSON (`{S,cfg,arch}`, без `ytKey`).

### Формат данных
`S = {queue:[], pending:[], current:null, history:[], evId}`. Поля трека: `id,text,nick,comment,rating,note,pl,title,author,name,skipped,src,tags,votes,vn,vavg,t0,thumb,cover,noemb`. Архив эфира: `{id,d,t:[{n,r,nick,tg,v}]}`, до 60 эфиров, автосохранение при каждом завершённом треке.

### Кнопки очистки (важно, не путать)
- **🗑 Новый эфир** (Настройки → Данные): сохраняет оценённые треки в архив, потом чистит очередь/историю. Это нормальное завершение вечера.
- **🧨 Очистить всё** (v12; Настройки → Данные и в окне «За 30 дней / За всё время»): с подтверждением стирает очередь, «На проверке», историю, текущий трек **и архив** `hmstr_arch`, сбрасывает голоса и заставку. Настройки, тема и фото ведущей остаются. Нужна, чтобы убрать тестовые треки из итогов «за 30 дней / за всё время». Функция `clearAll()`.

## Оверлей (`overlay.html`)
Получает данные от панели по WebRTC (PeerJS, `?room=КОД`, `cfg.room`, пир `hmstrfm-<room>`), запасной путь — `localStorage` (`hmstr_fm_v1`, `hmstr_theme`) через `storage` и опрос раз в секунду. Чат из `chat.eblo.id` по умолчанию канал `h_mst_r`; ссылки из панели передают `?chan=` из настроек (канал по умолчанию `h_mst_r`), `?chat=0` скрывает чат. Параметры: `?bg=green`, `?q=0` (скрыть очередь), `?logo=0`, `?scene=0` (без сцен). Показывает: выезд карточки, вращающийся винил, эквалайзер, штамп оценки с кольцом, пульсацию и конфетти на 9–10, дождь 🐹 на 10, 💀 на 1, чат-оценку в нижней строке карточки, список «Далее в эфире», сцены «Перерыв»/«Скоро начнём» с таймером. Оверлей целиком берёт тему панели. Название и исполнитель сжимаются до 2 строк. Убраны: аура из обложки, визуализатор, прогресс-бар, тикер оценок.

pubState (панель → оверлей): `t,pos,play,theme,blind,dur,vote,brk{rem,kind},ev{cnt,avg},hist,snd,sndVol,current{…,t0},queue`.

## Горячие клавиши (не ломать)
N следующий · Пробел пауза · 1–9, 0 оценка (0 = 10) · P плейлист · S пропуск · O открыть · ↑/↓ громкость · M звук · B слепой режим · T тема · D светлая/тёмная · K перерыв · L «скоро начнём».

## Ограничения
- В OBS: панель как Custom Browser Dock + оверлей как Browser Source (не проверено на практике). Запасной вариант: `overlay.html?bg=green` в окне браузера + Window Capture + Chroma Key.
- Бот читает чат, но не отвечает (нужен OAuth-токен и сервер). Работает только при открытой панели.
- Громкостью Spotify/SoundCloud из страницы управлять нельзя.
- Очередь и архив локальные (один браузер). Заявки с сайта от зрителей возможны только с сервером. Решено не делать публичную страницу для зрителей.
- Яндекс Музыка не даёт сторонним сайтам добавлять треки без своей авторизации.

## Не проверено на практике
Сцены в OBS, `watch_videos`, светлые темы (фоны упрощены), поиск обложки через iTunes (CORS), кнопка «🧨 Очистить всё» (v12, проверен только синтаксис).

## План (по приоритету)
1. Серверная часть (Vercel functions + KV/Upstash или Supabase): общее состояние для панели, оверлея и бота.
2. Бот с ответами в чат (OAuth, `!очередь`, `!скип` для модераторов, «твой трек в очереди №N»).
3. Альтернативные раскладки сторис («постер», «минимал»), просмотр архива по месяцам и список эфиров, удаление отдельного эфира из архива.
4. Публичная страница для зрителей (только если передумаем).
