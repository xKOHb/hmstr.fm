Ты помогаешь мне развивать сайт **HMSTR.FM**. Отвечай по-русски, коротко и по делу.

## Контекст
Моя подруга проводит радио-стримы на **Twitch**: зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, она слушает, ставит оценку и иногда добавляет трек в плейлист. Сайт нужен, чтобы ей было удобно это делать. Первый стрим на сайте будет на следующем эфире.

## Текущее состояние
- Сайт задеплоен: https://hmstrfm.vercel.app/ (GitHub → Vercel). Название везде просто **HMSTR.FM**.
- Один файл `index.html` (чистые HTML/CSS/JS, без сборки), рядом `og.png` (баннер 1200×630 для превью ссылки). Open Graph / Twitter мета-теги уже указывают на hmstrfm.vercel.app.
- Панель ведущей: заявка вручную (ссылка/название, ник, комментарий) → очередь (кнопки «играть сейчас» и удалить) → блок плеера → оценка 1–10 с подписью и анимацией (на 9–10 всплывают эмодзи) → заметка → «В плейлист» / «Пропустить» / «Следующий». История эфира, статистика (число треков, средняя оценка), «Скопировать плейлист», «Новый эфир».
- Плеер: YouTube через IFrame API (автозапуск, название и автор подтягиваются через `getVideoData`, размытая подсветка по обложке), Spotify и SoundCloud через встроенные iframe, остальные ссылки и названия — крутящийся винил и кнопка «Открыть».
- Громкость: слайдер, по умолчанию 50%, запоминается (`hmstr_vol`), работает только для YouTube. Mute, пауза/играть.
- 4 темы со своими анимированными фонами: hamster (семечки/тёплое свечение), neon (синтвейв-сетка и солнце), space (мерцающие звёзды и туманность), lagoon (круги на воде и плавающие пятна). Выбор хранится в `hmstr_theme`. Учитывается `prefers-reduced-motion`.
- Горячие клавиши: N следующий, Пробел пауза, 1–9 и 0 оценка (0 = 10), P плейлист, S пропуск, O открыть, ↑/↓ громкость, M звук, T сменить тему.
- Данные в `localStorage` (ключ `hmstr_fm_v1`): `{queue:[], current:null, history:[]}`; у элементов могут быть поля `id,text,nick,comment,rating,note,pl,title,author,skipped`.

## Ограничения и выводы
- Зрители пока не могут отправлять заявки на сайт сами, ведущая переносит их из чата вручную.
- В песочнице claude.ai встроенные плееры и открытие YouTube блокировались, поэтому сайт живёт на своём хостинге (Vercel).
- Громкостью Spotify/SoundCloud-встраиваний из страницы управлять нельзя.
- Очередь локальная (один браузер); для заявок от зрителей нужен сервер.

## План (по приоритету)
1. Общая очередь на сервере (Vercel serverless-функции + база, например Vercel KV/Upstash или Supabase), вместо localStorage.
2. Twitch-бот: команда `!заказ <ссылка или название>` добавляет заявку в очередь (tmi.js или EventSub).
3. Публичная страница для зрителей: форма заявки, очередь, лайки.
4. Оверлей для OBS (Browser Source): «Сейчас играет» и анимация оценки.
5. Антиспам: лимит заявок на ник, проверка дублей, чёрный список.
6. Хит-парад вечера и картинка-итог для сторис.
7. Подтягивание названия и обложки трека по ссылке.
