Ты помогаешь мне развивать сайт **HMSTR.FM**. Отвечай по-русски, коротко и по делу.

## Контекст
Моя подруга проводит радио-стримы на **Twitch**: зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, она слушает, ставит оценку и иногда добавляет трек в плейлист. Сайт нужен, чтобы ей было удобно это делать. Первый стрим на сайте — следующий, не сегодня.

## Текущее состояние
- Один файл `index.html` (чистые HTML/CSS/JS, без сборки и зависимостей), приложен.
- Будет лежать на GitHub и деплоиться на Vercel.
- Панель ведущей: ручное добавление заявки (ссылка/название, ник, комментарий), очередь, блок «Сейчас играет», встроенный плеер YouTube и Spotify, оценка 1–10, заметка, кнопки «В плейлист» / «Пропустить» / «Следующий», история эфира, кнопка «Скопировать плейлист», «Новый эфир».
- Горячие клавиши: N следующий, O открыть трек, S пропустить, P в плейлист, 1–9 и 0 оценка (0 = 10).
- Данные хранятся в `localStorage` (ключ `hmstr_fm_v1`): структура `{queue:[], current:null, history:[]}`.
- Тема: тёмная по умолчанию, акцент оранжевый (`#ff8a3d`), поддержка светлой темы.
- Есть баннер для превью ссылки `og.png` (1200×630) и Open Graph / Twitter мета-теги в `<head>`. В них нужно заменить `YOUR-DOMAIN` на реальный домен.

## Ограничения и выводы
- Зрители пока не могут отправлять заявки на сайт сами, ведущая переносит их из чата вручную.
- На хостинге claude.ai встроенные плееры и открытие YouTube блокировались песочницей, поэтому финальную версию размещаем на своём хостинге.

## План (по приоритету)
1. Общая очередь на сервере (Vercel serverless-функции + база, например Vercel KV/Upstash или Supabase), вместо localStorage.
2. Twitch-бот: команда `!заказ <ссылка или название>` добавляет заявку в очередь (tmi.js или EventSub).
3. Публичная страница для зрителей: форма заявки, очередь, лайки.
4. Оверлей для OBS (Browser Source): «Сейчас играет» и анимация оценки.
5. Антиспам: лимит заявок на ник, проверка дублей, чёрный список.
6. Хит-парад вечера и картинка-итог для сторис.
7. Подтягивание названия и обложки трека по ссылке.
